# Contributing

HAZA AIOS is a source-available showcase repository, not an open-source community project.

## Contribution Policy

External pull requests, feature requests, and issue reports may be reviewed at the owner's discretion, but no general right to modify, redistribute, sublicense, deploy, or commercially reuse the code is granted.

By submitting feedback, issues, or pull requests, you confirm that you have the right to share the submitted material and that your submission does not include secrets, private data, third-party confidential material, or unlicensed code.

## Public Review Guidelines

When reviewing this repository:

- Treat it as an active development portfolio project.
- Do not submit real credentials, student data, financial data, or personally identifiable information.
- Keep security-sensitive details out of public issues.
- Use the documented setup commands only with local placeholder configuration.

## Development Notes

The default branch is intended to represent the current showcase state. Feature branches may contain work in progress and may not be stable for review.
